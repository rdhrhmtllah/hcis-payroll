## Alasan

Berkas final baru masuk langkah **Terbit & Sebar**, bukan Pengesahan. Approved
karena itu cukup menuntut realisasi pengesah. Filing and Registered tetap
menuntut berkas final + realisasi pengesah.

sebelum pengesahan dinyatakan tuntas.
